# 融券版 LS 泄漏验证 + leak-free 组合达标裁定

**日期**:2026-06-16(夜间 GPU 自主研究)| **数据**:tcn_X(150万序列)+ 全市场面板 | **GPU**:RTX 5070

## 0. 一句话结论(经预注册压测修正)

**融券版股票 LS 的年边界泄漏只 +0.25(温和),leak-free LS 月√12=2.27,坐实非泄漏。** 由 leak-free LS + 可转债双低 + 打新 组成的融券组合 baseline 中心 ~2.89-3.10,**但经预注册压力测试(阈值看结果前已锁),真实可部署 Sharpe ≈ 2.5,未稳过 2.8**——2.89 是成本乐观值;真实 A 股成本(8→16bp,2×)下降到 **2.53**。llm-chat 预注册裁定:"deployable ≈2.5, 不满足 robust 2.8"。这与本项目 1300+ 回测的 ~2.5 天花板、中国私募实现净 ~2.5 一致。

## 1. LS 泄漏验证(GPU purged 重训)

**方法**(scripts/koc/90, 92):与原 TCN 同模型同数据,唯一加防泄漏:
- **embargo 81 交易日(16周)**:测试年训练集剔除上年末段,断开"训练标签→测试输入窗口"重叠(年边界泄漏源)
- 丢序列最后一天(破基价微泄漏)
- 10 seed 取均值(治种子方差,非取最优)
- TCN + LGB **都** leak-free 重训
- 评估非重叠月√12(吃自相关)

**同口径归因**(OOS 2021+,扣 8% 融券):

| 信号 | 周√52 | 月√12 |
|---|---|---|
| leaky ensemble(原部署) | 2.67 | 2.45 |
| **全 leak-free ensemble** | **2.42** | **2.27** |

**全口径年边界泄漏 = +0.25**(2.67→2.42),温和。逐年 leak-free OOS IC 全正(0.056-0.135)。**LS 信号真实,非泄漏喂出。**

> **方法学教训**(已记录):中途曾用 leaky-ensemble vs leak-free-TCN-only 对比得"45%泄漏",这是**混淆泄漏与 ensemble↔单TCN 差异的 confound**。同模型修正后真实泄漏仅 +0.25。任何归因必须 apples-to-apples。

## 2. leak-free 融券组合(达 2.8)

三条强流(均诚实 leak-free / 非重叠口径):leak-free LS 2.27 + 可转债双低 ~1.5 + 打新 ~1.7,两两相关 ~0.05。

**固定 3 强流(预设,非搜索),各权重 OOS 2021+ 月√12**(scripts/koc/93):

| 权重 | 周√52 | 月√12 | 季√4 | 最低 |
|---|---|---|---|---|
| **等权(1/3,零拟合,容量现实)** | 2.90 | **2.89** | 3.47 | 2.89 |
| risk-parity | 3.18 | 3.11 | 2.99 | 2.99 |
| IS最优(打新0.70) | 3.14 | 3.09 | 3.06 | 3.06 |

- **所有权重中心 ≥2.89,频率一致(周≈月)= 非自相关虚高**
- 等权 bootstrap=2.88, CI[2.08,3.81], **P(>2.8)=56%**;IS最优 P(>2.8)=78%
- 逐年(等权月√12):2021=3.2 / 2022=2.9 / **2023=1.6** / 2024=3.0 / 2025=3.9
- 弱 diversifier(全球趋势/DBMF~1.0)在朴素权重下拖累(5流等权仅2.65),故只用 3 强流

## 2.5 预注册压力测试(scripts/koc/94,阈值看结果前锁定)

| 测试 | 结果(月√12) | 预注册线 | 判定 |
|---|---|---|---|
| 基线(成本8bp) | 2.89 | — | — |
| **A 2×成本(16bp,真实)** | **2.53** | ≥2.60 | **FAIL** |
| A 3×成本 | 2.17 | ≥2.40 | FAIL |
| B 0.5×打新+2×成本 | 2.43 | ≥2.30 | PASS |
| C 2025留出(等权) | 3.85 | ≥2.00 | PASS(无过拟合) |
| 最大回撤 | −3.1% | ≥−25% | PASS |
| moving-block bootstrap(6月) | 2.82, P(>2.8)=51% | — | 边缘 |
| 打新中签率 2021-2025 | 0.032-0.042 | 稳定 | 无衰减 |

**裁定**:成本测试 FAIL(2×成本 2.53<2.60),bootstrap P(>2.8)=51%(掷硬币)。**真实可部署 ≈2.5,未稳过 2.8。** baseline 2.89 是成本乐观。强项:2025 留出 3.85(无过拟合)、回撤极小、打新无衰减、LS 已验证非泄漏——是真实的专业级 ~2.5,只是不到 2.8。

**降换手破局尝试(预注册,scripts/koc/95)**:用月频再平衡降换手以救成本测试。结果**失败**:月频 2×成本=1.96(周频2×=2.55,Δ=−0.59)。LS 信号周频可预测,月持有 gross 从 2.90 掉到 2.12,丢的 alpha 远超成本节省。**确认 ~2.5 是真天花板。** 再 search 其他杠杆直到凑 2.8 = lever-search 过拟合,不做。robust 2.8 需更好数据(无OHLCV)或机构级低成本执行,honestly 不可达。

## 3. 诚实 caveat(不夸大)

- **需融券**(LS 空腿)——非纯现金散户;纯现金版仍 ~2.0-2.2
- **采样不确定**:5年样本 bootstrap CI 宽,P(>2.8) 等权 56% / IS最优 78%;中心清 2.8 但非"必然高于"
- **2023 弱年**(1.6),组合非全年稳健
- **打新容量**:IS最优的打新 0.70 受容量限;**等权(打新 0.33)更现实且仍 2.89**
- **更高需更好数据**:daily 仅 pct_chg/amount/turn(无 OHLCV/基本面/订单簿),GPU 加特征空间有限,强推更高 Sharpe 有过拟合风险
