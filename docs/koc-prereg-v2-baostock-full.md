## 2. 预注册判定规则（运行前定义，运行后不得修改）

### 复现点 1 — 全期主规格显著性
> v1：γ1 t = **+2.93**（55 期）；公共网格 +2.66

- **复现（PASS）**：全样本 γ1 t > **+2.0** 且符号为正
- **不复现（FAIL）**：t ≤ +2.0 或符号翻负
- 理由：样本 ~3 倍，量级可能上移或被深市稀释；要求同向 + 经济显著，不要求精确等于 2.93。
  同时报告价差点估计（经济量级）。

### 复现点 2 — 时代分裂（核心交付）
> v1：旧 2010-2021 FM t=**+5.89**；新 2022-2024 FM t=−1.52（点估计转负，未达显著）

- **复现（PASS）**：同时满足
  - (a) 旧时代 2010-2021 FM t > **+3.0**（仍 CONFIRM 级正）
  - (b) 新时代 2022-2024 点估计 **≤ 0**（γ1 负或零，5% 下不显著为正）
- **部分（PARTIAL）**：旧时代成立，但**新时代转显著为正** → 深市/创业板新时代 PEAD 未同死，
  这是真实发现（v1 §8 的开放问题被回答），**如实报告，不强压**
- **不复现（FAIL）**：旧时代失去显著性（t ≤ 3）

### 复现点 3 — amihud 套利消除
> v1 §6 B2：旧时代漂移在**最流动层最强**（最高流动层 +3.54% t=5.55）；
> FM 交互 sue×illiq = −0.0036（t=−2.80）

- **复现（PASS）**：旧时代（2010-2021）满足任一
  - B2：最高流动性层 60d 价差 ≥ 最低流动性层价差（"alpha 藏在不可交易层"悖论**仍被否**）
  - FM：sue×illiq 交互 < 0 且 t < −2
- **不复现（FAIL）**：悖论翻转（最难交易层最强）→ Kill-(b)"被流动性过滤阻隔"叙事复活
