# Version B(融券)中性化突破:中心 Sharpe 清 2.8(实验笔记)

**日期**:2026-06-16 | **性质**:实验记录(best-so-far,非天花板)| **适用**:仅 Version B(融券/LS,需两融账户)

## 0. 一句话(经预注册压测 + llm-chat 裁定)

**用标准 style-neutralization(行业+市值中性化,a-priori、不调参、leak-free),LS 月 Sharpe 从 2.27 升到 2.68(+0.41),组合中心 Sharpe ≈ 2.9,在完整预注册 2×真实成本压测下达 2.94 ≥ 2.8,所有确定性测试全过。诚实 caveat:5 年样本 bootstrap P(>2.8)=52%,即中心清 2.8、统计置信约 50%。**

## 1. 杠杆:为什么有效且不过拟合

- **机制**:原 LS 跨全市场排名,残留行业/市值暴露 = 无补偿的因子方差(额外波动)。按行业去均值 + 对 size 回归取残差,剔除这些暴露 → 更纯市场中性 → 同收益低波 → IR 升。文献已知效应(剔除 priced factor 升 IR)。
- **a-priori 纪律**:行业+市值是教科书标准要中性化的风险因子,**看数据前定、停在两因子对**(不搜索还该中性化哪些 = 不过拟合)。
- **leak-free**:行业去均值、size 回归都是**当周点内截面**操作,l1/size 点内已知,无前视。

## 4. 可信度铁证(对照旧"急着庆祝")

- **频率一致**:周 3.35 ≈ 月 3.35(非自相关虚高)
- **换手不变**:双中性 LS 周换手 125% vs 基线 127% → **成本压测公平,涨的是纯 alpha 不是少交易**

## 5. 诚实定位

- **能说**:"Version B 中心 ~2.9,在完整预注册 2×真实成本压测下达 2.94 清 2.8,所有确定性测试过;标准 industry+size 中性化驱动,非过拟合;bootstrap 置信 ~50%(5 年样本)。"
- **不能说**:"必然/robustly 高于 2.8"(P>2.8 仅 52%)。
- **对照**:GP 理论已证成本不可压(a*≈1),所以这条路不是省成本,是**提 alpha**(中性化剔除无补偿方差)。OHLCV 新数据(抓取中)若再提 LS gross,置信度可进一步升。
