# 散户纯现金组合策略 — 产品说明

> ## ⚠️ 重要声明 —— 请务必读完
> 1. 这只是一个**实验性研究小工具**,不是投资系统,更不是赚钱机器。
> 2. **不要碰杠杆**(融券/配资/股指期货)、**不要碰期权**——普通散户碰这些大概率亏得更多。
> 3. 历史回测 Sharpe ~2.0-2.2 只是研究数字,不代表未来,不是任何收益承诺。
> 4. **不要以为靠这个能从股市稳定赚钱**——股市有风险,绝大多数散户长期是亏损的。
> 5. 仅供个人学习研究,非投资建议,一切操作后果自负。

**定位**:为**普通散户(纯现金账户)**生成每周可操作的多 sleeve 组合信号。无融券、无股指期货、无期权(这些普通散户接触不到)。

## 诚实业绩(必读,严禁夸大)

**净 Sharpe ≈ 2.0–2.2**(非重叠月度 √12,已对 1300+ 配置选优做多重检验 deflated)。

- 口径:**非重叠月度**收益直接年化,吃掉了周线 √52 的正自相关虚高(可转债持仓趋势、打新 lumpy 会把周线口径抬高 ~15-25%)。
- **纯现金不可达 Sharpe 3**:唯二强且正交流 = 可转债双低(月 SR~1.5)+ 打新(~1.7),√(1.5²+1.7²)=2.28 是数学上限;52 因子动物园证实不存在第 3 条正交 SR≥1.5 纯现金流。
- 行业对标:Sharpe 3 净值超过中国私募行业天花板(顶级量化中性实现净 1.4-2.3、多策略 1.8-2.4)。**~2.0-2.2 已是专业水准。**
- ⚠️ 回测中心值,非保证;实盘需纪律执行 + 风控。研究信号非投资建议。

详见 [koc-sharpe3-investigation.md](koc-sharpe3-investigation.md)。

## 三条纯现金 sleeve + 配置(以 100 万为例)

| sleeve | 占比 | 金额 | 说明 |
|---|---|---|---|
| 底仓(低波红利个股) | 33% | 33 万 | 提供打新市值(**必须个股**,ETF/基金/可转债不计入打新市值);低波+红利+质量压低 2022 式回撤 |
| 可转债双低 | 37% | 37 万 | 价格 88-128、溢价<40%、高于纯债价值,双低排名前 25 等权 |
| 逆回购 | 30% | 30 万 | 闲置现金收益 + 打新缴款流动性缓冲 |

> 底仓 >40% 会把组合 Sharpe 拖到 2.0 以下;<30% 打新额度不足。**33% 是结构性甜点,非偏好可调。**

## 风控(实盘必查)

- **可转债强赎**:持有债出现强赎公告 → 赎回日前(≤3 交易日)清仓(本工具未接强赎实时源,需人工核对公告)
- **可转债信用/退债**:已自动排除含"退"字债;留意评级下调,1 交易日内卖出
- **打新破发**:科创/创业板可能破发;次日跌破发行价 >15% 止损;首日破发的不申购
- **单只可转债集中度** ≤ 可转债 sleeve 的 5%(已在等权 25 只中满足)

## 用法

```bash
# 每周末跑一次,出当期清单(默认 100 万)
.venv/Scripts/python.exe scripts/koc/retail_signal.py 1000000
# 输出:docs/retail-signal-latest.md(报告) + data/retail_signal_latest.json(结构化)
```

## 架构

| 文件 | 职责 |
|---|---|
| `lib/portfolio/retail_cash.py` | 核心纯函数:双低过滤、退债/强赎排除、配置拆分、集中度、破发止损、底仓筛选、业绩披露 |
| `scripts/koc/retail_signal.py` | CLI:实时数据(akshare 打新 + 本地可转债)+ 报告/JSON 输出 |
| `test/portfolio/test_retail_cash.py` | 28 项纯函数断言测试(无需 pytest) |

数据来源:akshare 公开数据 + 本地 `data/cb_value.parquet`。无凭证、无外部上传。
