## 3. 双源对账：发现 baostock net_profit 线的归母污染（重要）

§12 reconcile（股本稳定子集法）输出"54.8% 重述率、判定 SERIOUS、baostock 更可靠"——
**这个 verdict 是错的**，根因是脚本拿两条**不同 EPS 线**硬比：

**spot-check 决定性证据**（单季归母基准）：

| 股票 | 已知归母 | baostock(net_profit/total_share) | akshare(eps_ytd) |
|---|---|---|---|
| 茅台 2023Q4 | 17.400 | 18.066（+3.8%） | **17.400 精确** |
| 平安银行 2023Q4 | 0.310 | 0.351（+13.4%） | **0.310 精确** |

- **akshare eps_single = 干净的归母线**（精确命中基准）
- **baostock net_profit/total_share = 含少数股东/优先股，系统性偏高 ~6%**（银行达 13%）
- 系统性方向：|EPS|>0.20 子集上 akshare < baostock 占 **60.8%**，均值差 −5.9%
- 加绝对 EPS 下限后重述率不降到 0（|EPS|>0.20 仍 34.5%）→ 证明是**口径差非 near-zero 噪声**

**因此**：54.8% 绝大部分是归母 vs net_profit 的**口径差，不是重述**。§12 当前方法**无法做真重述
检测**，因为两源不在同一条线上。真重述检测需要 baostock 也出归母线（epsTTM 推导）再比。

### 这对 KoC 结论意味着什么

1. **不影响 v1→v2 对照有效性**：v1 与 v2 都用 baostock net_profit 线，同口径，复现成立。
2. **但 v1+v2 都建在被污染的归母线上**（系统性偏高 ~6%）。SUE 是标准化量，稳定的少数股东占比
   在 (actual−expected) 与标准化分母里大部分抵消 —— 这解释了污染线上信号仍强（旧 t=8.73）。
3. **指向一个确认性重跑**（轴 B，原被推迟，现有硬证据支撑）：用 baostock epsTTM 归母线
   （§11 Path B）重建 SUE，验证 3/3 复现是否仍成立。若仍成立 → 结论对 EPS 线选择稳健，
   且 baostock 归母线可与 akshare 归母线做**真·跨源对账**（同线比较，才能隔离真重述）。
